# Product Terminology

- **AI-Hydro:** the full autonomous hydrologic research platform.
- **AI-Hydro Studio:** the shared interactive runtime for artifacts and learning.
- **Artifact experience:** reports, dashboards, visualizations, diagnostics, and executable analyses.
- **AI-Hydro Learn:** courses, modules, progress, assessments, and guided learning inside Studio.
- **HydroLab:** an executable learning module with scientific checks.
- **HydroGuide:** the context-aware tutor behavior.
- **Learning Pack:** an installable, versioned course or module bundle.
- **HTML Preview:** legacy implementation and compatibility terminology during migration.
